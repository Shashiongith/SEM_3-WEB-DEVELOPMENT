# React Learning Project

This repository is a hands-on React practice project built with Vite. It contains a collection of small components, demos, and assignment-based exercises designed to help learners understand the fundamentals of modern React development.

The project covers key concepts such as:
- Components and props
- State management
- Event handling
- Hooks such as useEffect
- React Router and navigation
- Context API basics
- Practical UI examples and assignments

## Technologies Used
- React
- React Router DOM
- Vite
- JavaScript / JSX

## Project Purpose
This folder is intended for learning and practicing frontend development with React. It is a simple yet effective workspace for exploring core concepts through interactive examples and structured exercises.

## Getting Started
1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Open the local URL shown in the terminal to view the project in the browser.

Feel free to explore, modify, and build upon the examples to strengthen your React skills.
